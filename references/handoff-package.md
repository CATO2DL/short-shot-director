# 精简的视频素材文件夹

## 交付原则

最终文件夹只放本镜头实际需要的图片和可直接使用的提示词。生成候选与用户自带图采用同一标准：选中一组不代表要把整组视角全部放进去，只保留用于当前视频输入或必需结构约束的图。

用户明确选定图片后再整理。候选阶段需要的 ID、模型、父参考、选择与检查信息在当前会话中维护，不另建日志或记录文件，不把内部设计过程装进交付包。完整 11 节镜头模板用于设计或用户明确要求的方案文档，默认素材包不包含 shot.md。

## 默认目录

只有首帧就能制作时，最小交付如下；这是结构示意，不表示媒体已经存在：

```text
S01-cloud-palace/
  start.jpg
  video.txt
```

确实需要时再添加：

- `end.jpg`：仅在末帧约束有明确作用、目标工具确认支持且图片已实际获得时加入。
- `reference-side.jpg` 等：用于当前镜头必需的身份／结构约束，且有清楚用途；只用于挑选或对比的角度不带入。
- `image-prompts.txt`：仅保留包内图片实际使用且仍需复用／修改的完整图片提示词；不附生成历史。自带图没有原词就不创建此文件，不编造重建词凑数。用户只需视频词时省略。

扩展名服从真实格式；复制原图字节，不把 JPEG 改名为 PNG。文件名清楚表达首帧、尾帧或参考角色，提示词引用同一文件名。不需要额外层级、空目录或占位文件。

## 提示词内容

`video.txt` 开头可用几行写清目标视频模型、已确认的输入模式和所需文件的角色，紧接完整可复制的视频提示词。仅保留实际执行所需信息，不加入选择证据、生成时间、版本历史、来源追踪、检查报告或长篇制作说明。

提示词描述一个场景、一段明确动作、一种主要运镜，区分主体与环境运动，并明确首尾构图。已确认需要独立排除字段时，可在同一文件中标明该字段内容。平台未确定时写明工具中立，不编造模型、模式、槽位或参数。

如保留 `image-prompts.txt`，以包内图片文件名分段，放对应的完整图片提示词；仅在实际复用需要时注明图片模型。不能将后来没执行过的修订词冒充该图实际生成词。必要的新修订词明确标为待执行，不自动重生图片。

## 不要交付的文件

不创建或打包 README.md、manifest.json、shot.md、候选表、来源说明、用户原话备份、模型追踪、选择记录、验收报告、重试日志、旧版提示词或对比拼图。不把未选候选、选定组内无关视角、失败图、重复图、缩略图、缓存或临时文件混进去。用户明确另要某项时再单独提供。

将 ZIP 放在素材文件夹之外，ZIP 里只包含该精简文件夹；不放进它自己，也不附额外校验或记录文件。Skill 源码仓库本身的 README、LICENSE、指南、模板和发布校验文件不属于生成的镜头素材包，不受此处删减规则影响。

## 整理与清理

新交付从选定的必要文件重新组装，默认不创建多余记录。若正在精简本任务已生成的交付目录，删除其中由本技能生成的多余记录、候选与重复文件，并同步重建 ZIP；只在该明确的输出目录内清理，不删除用户原始素材、外部工作目录或与本任务无关的文件。原图在源位置保留，不因从包中移除而删除源文件。

没有完整图片文件或导出能力时，在回复中说明缺图，不建立假路径、空图或占位媒体。需要生图但工具不可用时只能交付提示词，不能声称图片包已完成；自带图足够时不需要图片生成工具。未知原图片模型、原词不阻塞自带图流程，也不需要生成来源说明文件。

## 交付前检查

- 每张图都对应当前镜头的具体用途，没有仅为审阅、备份或凑数保留的图。
- 文件真实存在、可读取、格式正确；视频提示词引用的文件名与包内一致，没有无效首尾帧或参考角色。
- 图片、运镜、主体动作、环境运动和结尾构图一致；工具能力未知时明确是工具中立提示词。
- 目录中只有必要图片与提示词；没有上述记录、旧版或临时文件。
- ZIP 可解压、内容与精简文件夹一致，已过时的旧 ZIP 不作为当前交付链接。

最终回复给出文件夹和 ZIP 链接，必要时附图片预览；缺口或未生成视频的状态在回复中简短说明，不另建状态文件。制作素材包不等于获准调用视频生成接口。
