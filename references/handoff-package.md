# 一份 Markdown 镜头文档

## 默认交付

最终只交付一份供用户阅读和复制提示词的 Markdown，默认命名为 `shots.md`。每个镜头按「镜头 1｜名称」「镜头 2｜名称」顺序排列，固定内容顺序为：建议时长 → 一张或几张必要视角图片 → 完整视频提示词。使用 [交付模板](../templates/shots.md)。不要拆成每镜头一份文件，不再默认生成独立 video.txt 或 image-prompts.txt。

只有一个镜头时就写「镜头 1」，不要为凑序号创造额外镜头。用户提供多个短镜头时合并到同一文档，每个镜头仍各自满足一个场景、一段动作、一种主要运镜；不自动扩展成多场景剧情。n 组候选是同一镜头的备选方案，不等于 n 个最终镜头。

完整 11 节镜头模板仅用于设计检查或用户明确要求的详细方案，默认不把参数表、素材表、日志、验收记录或修复历史放入最终文档。需要维护的模型、候选和派生信息留在会话中。

## 每个镜头的内容

1. 标题：`## 镜头 1｜云隙见殿`。编号按用户顺序，名称简短描述画面。
2. 时长：`建议时长：5 秒`。结合动作、发现节奏和结尾停留给具体建议，用户已指定时优先遵守。工具有已确认时长限制时按实际能力调整并简短说明；未知时只是设计建议，不编造可执行时长档位。
3. 图片：嵌入实际选定的首帧，以及当前镜头确实需要的一张或几张视角图。每张用简短文字标明「首帧／正面」「侧面参考」或「尾帧」。只有首帧就足够时只贴一张，选中组内的无用角度不保留。侧面参考不自动等于第二个镜头或尾帧。
4. 提示词：图片之后放一个完整视频提示词代码块，可直接复制。描述开始、中段、结束，分清相机、主体与环境运动。必要的目标模型、画幅、已确认模式或参考角色用一行说明；全篇相同时可只在文档顶部写一次。

若用户还需要图片提示词，在对应镜头的视频提示词之后加一个明确标注的代码块，不另开文件。自带图没有原始提示词时不编造，也不附来源说明文件。未经执行的重建／修改建议要明确说明，不能当作原词。

## 真实图片与便携性

Markdown 用图片嵌入语法展示，而不是只列文件路径。只有实际存在、已查看且选定的图片才写入图片链接；未生成时写「图片：待生成」，不建立虚假图片路径或占位图。

下载文档默认采用相对图片路径，让图片与文档一起移动后仍可显示。只附上文档引用的必要图片，例如：

```text
shot-delivery/
  shots.md
  images/
    shot-01-start.jpg
    shot-02-start.png
    shot-02-side.png
```

这仍是一份 Markdown 正文，images/ 只存显示图片所必需的附件，不是额外记录。保持真实图像格式，不把 JPEG 字节改名为 PNG；相同图片被多个镜头使用时可共用一份文件。不要依赖用户机器的绝对路径作为可下载文档的引用。聊天中的本地图片预览仍使用宿主要求的绝对路径。

若用户明确要求磁盘上也只有一个 .md 文件，先核实目标阅读器是否支持内嵌图片；不要假定 Markdown 阅读器支持 data URI，也不能删除图片附件导致显示失效。无法兼容时说明必须保留的图片附件，而不是声称单文件已自包含。不要默认用体积庞大的 base64 填满文档。

提供 shots.md 下载链接；为便于图片随文档下载，可同时提供只含 Markdown 与所需 images/ 的 ZIP，ZIP 放在输出文件夹外。用户阅读入口始终是这份 Markdown，不要求另读 README 或提示词文本文件。

## 清理和检查

最终包不包含 README、manifest、候选表、选择证据、来源说明、模型追踪、原话备份、旧版提示词、检查报告、日志、重复图、未选候选或无用视角。Skill 源码仓库的安装 README、LICENSE、指南、模板与发布校验文件仍保留，它们不是生成的镜头交付包。

将本任务旧版的必要提示词合并进 shots.md 后，移除输出目录内由本技能生成的旧提示词文本与多余记录，并重建下载 ZIP；不删除用户原始素材或其他项目文件。确认没有缺失内容再清理，保留源位置的原图。

交付前检查：每个镜头有名称、具体建议秒数、真实必要图片（或明确待生成状态）和完整提示词；图片引用可解析，图片确实嵌入而非普通链接；首帧、参考图与提示词对应，镜头编号与候选组号不混淆。核对工具支持的输入模式；没有多参考能力时，不因为展示了多张图就声称可全部上传。

能使用 Markdown 预览工具时检查图片实际显示；否则至少检查文件与引用，并说明未做渲染检查，不声称视觉验收通过。ZIP 解压后相对图片路径仍须有效，内容与最终文档及图片一致。缺图或工具不可用时在文档对应镜头和回复中简短说明。没有生成视频就不声称已完成视频；不自动调用付费视频接口。
