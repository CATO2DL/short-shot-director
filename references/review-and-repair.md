# 审阅、自然语言修改与局部修复

## 先区分两种审阅

方案审阅：检查文字的空间和时间逻辑、参考必要性、提示词一致性与工具可执行性。可以在未生图时完成。

视觉审阅：必须实际查看生成的图像／视频。记录查看了哪些素材、哪些时段或抽帧。未生成的内容保持「待生成」；只能抽帧时，不声称验证了全部运动连续性、无闪烁或无抖动。

## 反馈翻译

| 用户反馈 | 具体修改建议 | 依赖检查 |
| --- | --- | --- |
| 更宏大 | 缩小人物画面占比，增加层次与尺度参照，延伸建筑边界 | 起始构图、纹理尺度、首尾画面；不默认增加人物或运动 |
| 不要恐怖 | 去掉威胁符号、异常面孔和突变；柔化阴影、保留暗部细节 | 光线、色彩、材质、排除项与情绪目标 |
| 颜色暖一点 | 主色转暖灰或米白，主光略暖，控制高光与金属反射色 | 首尾图、辅助色、材质、视频光照稳定条件 |
| 镜头不要动，人走过去 | 相机位置、朝向和焦段固定，人物从明确起点走到终点 | 清除跟随／推进，调整时间段、主体终点与验收 |
| 从侧面看 | 明确看主体哪个侧面，改起始位置与朝向 | 新可见面、身份参考、首帧、结束构图；不擅自变成环绕 |
| 人物更小 | 降低人物相对画幅高度并增加空间留白 | 服装可辨细节、首帧；不靠无意义变焦实现 |
| 最后抬头看不到墙顶 | 将语境中的抬头落实为相机原地向上摇，末帧只见延伸墙面 | 若指人物抬头则另设主体动作；清除露出墙顶的旧尾帧 |

「抬头」或「从侧面」存在会改变核心动作的歧义时，结合现有镜头判断；仍无法判定再提一个简短问题。每轮最多两个问题。调整幅度、色值等非阻塞信息用明确标注的建议值。

## 修改操作

保留镜头 ID，递增方案版本。写出本轮变更字段，沿依赖更新参数表、素材表、提示词、时间变化、排除项与验收条件。只将受影响的已有媒体标为需重生成；不要删除或假称重做了未受影响素材。主参考变更会使其派生图失效。

候选阶段沿用组 ID 与视角 ID、递增图片版本，重新展示受影响图片并等待用户选择。用户改选组后，重新建立该组的首帧与绑定关系，视频素材包递增版本；旧组图片不能留在新包中充当当前输入。只更换视频目标模型通常更新 video.txt 内的适配与输入说明，不自动重生成所有图片；若新模型的实际输入要求不兼容，再具体处理受影响图片。

交付更新后的完整首帧与完整视频提示词；若尾帧／补充视角受影响，也输出其完整新版本。局部修复句可额外提供，但不能只给一句补丁让用户自行拼接含矛盾的旧提示词。

## 观察到失败后修哪里

| 失败 | 首先检查 | 局部修复句示意 |
| --- | --- | --- |
| 向上摇被做成升高 | 是否含飞升、升空、鸟瞰等冲突词 | 相机固定在原地同一高度，只绕固定机位向上转动；地面逐渐退出画面 |
| 横移变成宫殿移动 | 场景是否被写成漂浮运动主体 | 宫殿固定在云上空间，相机缓慢向右平移，前景位移快于远景 |
| 转头变脸 | 主参考是否清晰，侧脸是否来自同一身份 | 维持同一人的脸型与五官比例，仅缓慢转动头部，肩膀不转 |
| 产品环绕时结构改变 | 新露出侧面是否有结构依据 | 保持按钮、接口与接缝的固定物理位置，只改变相机观看角度 |
| 结尾越过目标 | 时间与减速段是否明确，工具能否约束尾帧 | 在目标构图前平滑减速并停留，禁止继续越过该角度 |
| 图像拼贴／文字污染 | 是否把设定板当首帧 | 使用干净单图，画面无文字标注、边框与分格 |

把示意句融入完整新提示词前，删除冲突旧句。若结构缺失，先补结构参考，不能靠更长的排除词解决。若工具不支持所需动作，简化路径或交付工具限制，不谎称已修复。

## 验收顺序与重试边界

1. 主体数量与身份／结构是否稳定，场景是否仍为单一连续空间。
2. 相机位置／朝向／焦段变化是否符合声明，主体与环境是否各按自身指令运动。
3. 起止构图、遮挡、揭示内容和结束情绪是否成立。
4. 光线、配色、材质与禁止项是否一致，是否出现切镜、变形、闪烁、文字污染。
5. 只根据观察到的失败选择最小修复；不要为了可有可无的细节重新生成全部素材。

生成次数、费用及重试范围服从用户已有授权。未约定自动重试时，先给修复方案；连续两次出现同类核心错误时停止相同策略，说明需要补参考、简化动作或换可用工具。不要用反复付费试错掩盖能力缺口。
